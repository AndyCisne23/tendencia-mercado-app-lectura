#### ESPAÑOL
# 📚 Análisis de Mercado para App de Lectura (SQL & Python)
---

## 🛠️ Herramientas
* **Lenguaje:** Python (Jupyter Notebook)
* **Manipulación de Datos:** Pandas
* **Extracción y Consultas:** SQL (Conexión a bases de datos relacionales, uso de agregaciones, funciones de ventana y subconsultas)

## 📝 Descripción del Proyecto
Este proyecto simula un análisis estratégico de mercado para una startup del sector editorial, enfocado en evaluar datos de libros, autores, editoriales, calificaciones y reseñas de usuarios recopilados durante un contexto de auge en la lectura desde casa. 

El objetivo principal fue procesar una base de datos relacional mediante **consultas SQL** para responder a preguntas clave de negocio (como volumen de publicaciones post-2000, identificación de editoriales y autores destacados, y comportamiento de usuarios muy activos) generando una base analítica para la propuesta de valor de un nuevo producto.

## 🔍 Fases y Tareas del Análisis
El desarrollo del proyecto se estructuró en las siguientes etapas analíticas ejecutadas mediante SQL:
1. **Volumen de Publicaciones Recientes:** Conteo de libros publicados a partir del 1 de enero de 2000.
2. **Métricas de Interacción:** Cálculo del número total de reseñas y calificación promedio por cada libro.
3. **Filtro Editorial:** Identificación de la editorial con mayor producción de libros relevantes (excluyendo publicaciones menores de 50 páginas).
4. **Autor Destacado:** Análisis de calificación promedio por autor, aplicando filtros de relevancia (mínimo 50 calificaciones por libro).
5. **Comportamiento de Power Users:** Determinación del promedio de reseñas de texto generadas por los usuarios más activos (aquellos que calificaron más de 50 libros).

## 💡 Conclusiones Principales
* El uso de consultas SQL optimizó la extracción de métricas agregadas directamente desde la base de datos relacional, evitando procesar pesados volúmenes de datos de forma manual en Pandas.
* Los filtros aplicados sobre calificaciones mínimas y número de páginas permitieron aislar datos de alta calidad para perfilar correctamente a las editoriales y autores más influyentes del mercado.

#### ENGLISH
# 📚 Market Analysis for a Reading App (SQL & Python)
---

## 🛠️ Tools
* **Language:** Python (Jupyter Notebook)
* **Data Manipulation:** Pandas
* **Extraction and Queries:** SQL (Connecting to relational databases, using aggregations, window functions, and subqueries)

## 📝 Project Description
This project simulates a strategic market analysis for a startup in the publishing industry, focused on evaluating data on books, authors, publishers, ratings, and user reviews collected during a boom in at-home reading.

The main objective was to process a relational database using **SQL queries** to answer key business questions (such as the volume of publications since 2000, the identification of prominent publishers and authors, and the behavior of highly active users), thereby generating an analytical foundation for the value proposition of a new product.

## 🔍 Phases and Tasks of the Analysis
The project was structured into the following analytical stages, carried out using SQL:
1. **Volume of Recent Publications:** Count of books published since January 1, 2000.
2. **Engagement Metrics:** Calculation of the total number of reviews and the average rating for each book.
3. **Publisher Filter:** Identification of the publisher with the highest output of relevant books (excluding publications with fewer than 50 pages).
4. **Featured Author:** Analysis of the average rating per author, applying relevance filters (minimum of 50 ratings per book).
5. **Power User Behavior:** Determination of the average number of text reviews generated by the most active users (those who rated more than 50 books).

## 💡 Key Findings
* The use of SQL queries optimized the extraction of aggregated metrics directly from the relational database, avoiding the need to manually process large volumes of data in Pandas.
* Filters applied to minimum ratings and page counts allowed us to isolate high-quality data to accurately profile the most influential publishers and authors in the market.
